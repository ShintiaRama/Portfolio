Data QASample project

Rescuing a 48,000-Record B2B Customer Database

Context
A packaging supplier selling to business buyers had merged exports from its online store, accounting software and email tool into one spreadsheet that nobody trusted.
Problem solved
The file held about 11,200 duplicate accounts, phone numbers in six formats, mixed date styles and hand-typed country names. Invoices bounced and the same buyer received three newsletters.
Duration
3 weeks
Tools
Excel, Power Query
Delivered
Clean master file, data dictionary, change log

Result

I wrote a data standard, built Power Query rules to normalize every field, and reviewed the 1,900 uncertain matches by hand. The cleaned file imported into the new CRM with zero rejected rows.

11,200 duplicates merged0 rejected rows

SOP creationSample project

Customer Support SOP Handbook Built on ISO 9001 Principles

Context
An online homeware store had a support team of eight agents and no written procedures. Refunds, escalations and complaints were handled differently on every shift.
Problem solved
New agents learned by guesswork, the same issue could get three different answers, and managers had no record of why decisions were made.
Duration
4 weeks
Tools
Word, Visio, Canva
Delivered
SOP handbook (PDF), checklists, revision log

Result

I interviewed the team lead, mapped each process in Visio, then wrote 14 SOPs with one structure: purpose, scope, responsibilities, steps, records and revision history. Each has a one-page checklist for live chats. Onboarding dropped from three weeks to ten days.

14 SOPs40% fewer escalation errors
